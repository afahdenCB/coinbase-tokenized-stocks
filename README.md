# Coinbase Tokenized Stocks

A CoW Swap-compatible token list for Coinbase tokenized stocks on Base.

## Token list URL

```text
https://raw.githubusercontent.com/afahdenCB/coinbase-tokenized-stocks/main/CowSwap.json
```

The list follows the standard token-list JSON format used by CoW Swap. Token logos are stored in [`assets/`](./assets).
